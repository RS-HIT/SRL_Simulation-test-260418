# 2026-04-17 关节角拖动调试器闪退修复

## 问题现象

运行 [debug_joint_angle_tuner.py](/e:/project/codetest/SRL2_learning/scripts/debug_joint_angle_tuner.py) 时，终端出现下面的告警，随后窗口很快关闭：

```text
WARNING: Insufficient arena memory for the number of constraints generated.
Increase arena memory allocation above 13M bytes.
```

## 根因分析

这次退出不是“滑块逻辑有问题”，而是 MuJoCo 运行时场景和调试器使用方式叠加导致的：

1. [urdf_0.1.4.2_runtime_scene.xml](/e:/project/codetest/SRL2_learning/assets/external_models/urdf_0.1.4.2/runtime/urdf_0.1.4.2_runtime_scene.xml) 之前没有显式 `<size memory="...">`，arena memory 太小。
2. 真实网格模型加地板后，首帧就可能生成大量接触约束。
3. 关节角拖动调试器本质上只需要“摆姿态并观察”，并不需要真实接触约束，但之前没有禁掉 contact。
4. viewer 线程里如果发生异常，原脚本也没有把错误显式打印出来，导致表现成“闪退”。

## 本次修改

### 1. 提高 runtime scene 的 arena memory

修改文件：

- [urdf_real_mesh_mujoco.py](/e:/project/codetest/SRL2_learning/src/srl2_learning/adapters/urdf_real_mesh_mujoco.py)

改动要点：

- 新增 `DEFAULT_REAL_MESH_ARENA_MEMORY = "64M"`
- 在 `_inject_default_like_scene_into_mjcf(...)` 中强制补 `<size memory="64M" />`
- 即使复用已有 runtime scene，也会重新补齐这段 scene 配置，而不是只在首次生成时注入

### 2. 在关节角拖动调试器里禁用 contact

修改文件：

- [debug_joint_angle_tuner.py](/e:/project/codetest/SRL2_learning/scripts/debug_joint_angle_tuner.py)

改动要点：

- 在加载模型后设置：
  - `model.opt.disableflags |= mjDSBL_CONTACT`
- 这让调试器只做位置直达和前向运动学刷新，不再为地板/真实网格接触分配大量约束内存

### 3. viewer 线程异常显式打印

修改文件：

- [debug_joint_angle_tuner.py](/e:/project/codetest/SRL2_learning/scripts/debug_joint_angle_tuner.py)

改动要点：

- 给 `_viewer_loop(...)` 加 `try/except`
- 异常会直接打印 traceback
- Tk 窗口里也会显示 `viewer 状态`

