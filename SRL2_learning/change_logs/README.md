# 改动日志目录

这个目录用于记录 `SRL2_learning` 当前版本之后的每次改动。

建议规则：
- 每次完成一轮明确修改后，新增一份日志文件。
- 文件名建议使用 `YYYY-MM-DD_主题.md`。
- 每份日志至少记录：
  - 本次改了什么
  - 改了哪些文件
  - 为什么要改
  - 是否做了验证
  - 还有哪些已知边界或未完成项

推荐模板：

```md
# 标题

## 日期
- 2026-04-16

## 本次目标
- 简述这次改动的目标

## 修改内容
- 改了什么

## 涉及文件
- 文件路径

## 验证
- 跑了什么命令
- 结果如何

## 备注
- 已知限制
```
