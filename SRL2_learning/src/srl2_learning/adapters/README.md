# 适配层说明

当前目录用于存放“原项目强平台/强依赖模块”的学习版适配层。

## 当前已提供
- `mock_actuator.py`
  - 替代原项目中的真实电机下发
  - 只记录命令，不访问硬件

- `offline_joint_visualization.py`
  - 教学版离线仿真和图表导出
  - 主要服务于最小主链路

- `mujoco_replay.py`
  - 原 `Rsras1.xml` 的运行时适配
  - 负责无网格清洗、`qpos` 写入、viewer 回放、离线 GIF、CSV 和轨迹图导出

## 当前策略
- 能离线替身化的，先做 mock 或教学适配
- 依赖真实设备协议的，先写中文说明和接口壳
- 对当前无法确认的行为，先明确标“待确认”，不擅自补写

## 当前 MuJoCo 适配边界
- 使用的是原 `SRL2/model/Rsras1.xml` 的结构
- 不是原项目完整外观
- 当前由于 STL 缺失，默认运行在无网格结构回放模式
- 第一版只驱动右侧 SRAs 机械臂
