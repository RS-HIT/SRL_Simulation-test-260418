## 基本一致但仍需确认

### 1. 轨迹规划主流程

- 验证位置：`tests/test_pipeline.py`、`examples/minimal_joint_motion.py`
- 验证方法：
  - 跑通“规划 -> 状态更新 -> 动力学接口 -> 映射 -> 执行记录”
- 结论：基本一致但仍需确认
- 原因：
  - 学习版当前使用的是线性插值替身
  - 原项目实际使用 Reflexxes Type II
  - 两者接口流程相近，但数值轨迹并不等价

### 2. 动力学接口接入位置

- 验证位置：`tests/test_pipeline.py`
- 验证方法：
  - 在主链路中实际调用 `OfflineDynamicsService.inverse_dynamics`
- 结论：基本一致但仍需确认
- 原因：
  - 当前只验证了接口接入位置和调用顺序
  - 没有验证真实 RBDL 数值结果
