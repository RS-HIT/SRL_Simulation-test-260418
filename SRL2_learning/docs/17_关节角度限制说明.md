# 17_关节角度限制说明

这份说明专门讲一件事：

**如何给每个关节设置允许角度范围，并让逆运动学只在这个范围内求解。**

## 1. 现在的功能是什么

现在 `SRL2_learning` 已经支持：

- 为每个关节单独设置上下限
- 逆运动学迭代时自动裁剪到这个范围内
- 初始关节姿态也会先被裁剪到这个范围内

也就是说，求解不再是“默认无限转”。

---

## 2. 去哪里设置每个关节的角度限制

配置文件：

- [cartesian_target_experiment.json](/e:/project/codetest/SRL2_learning/configs/cartesian_target_experiment.json)

推荐直接使用这个字段：

```json
"joint_position_limits_degrees": {
  "J1": [-170.0, 170.0],
  "J2": [-170.0, 10.0],
  "J3": [-170.0, 170.0]
}
```

这里的键必须是模型中的关节名，例如：

- `J1`
- `J2`
- `J3`

值的含义是：

```text
[下限角度, 上限角度]
```

单位是角度，不是弧度。

---

## 3. 如果你想直接用弧度

也可以使用：

```json
"joint_position_limits_radians": {
  "J1": [-2.967, 2.967],
  "J2": [-2.967, 0.1745],
  "J3": [-2.967, 2.967]
}
```

优先级规则是：

1. `joint_position_limits_radians`
2. `joint_position_limits_degrees`
3. 模型原始限位

也就是说，如果你同时写了弧度和角度配置，代码会优先采用弧度配置。

---

## 4. 这些限位在代码里哪里生效

### 4.1 关节限位读取和覆盖

文件：

- [model_context.py](/e:/project/codetest/SRL2_learning/src/srl2_learning/kinematics/model_context.py)

关键入口：

- `load_real_mesh_model_context(...)`

这里会做两件事：

1. 先读取模型本身自带的 `jnt_range`
2. 再用你在实验配置里写的每关节上下限去覆盖

### 4.2 关节裁剪

同样在：

- [model_context.py](/e:/project/codetest/SRL2_learning/src/srl2_learning/kinematics/model_context.py)

函数：

- `clamp_joint_positions(...)`

作用是：

```text
如果某个关节超出上下限，就把它夹回允许范围
```

### 4.3 逆运动学迭代中生效

文件：

- [inverse_kinematics.py](/e:/project/codetest/SRL2_learning/src/srl2_learning/kinematics/inverse_kinematics.py)

在每轮迭代里，更新后的关节角都会经过：

```python
current = self.model_context.clamp_joint_positions(current + delta_joint)
```

这意味着：

- IK 不会把关节角推进到你设定范围之外

### 4.4 初始姿态也会生效

文件：

- [cartesian_target_experiment.py](/e:/project/codetest/SRL2_learning/src/srl2_learning/experiments/cartesian_target_experiment.py)

在实验开始前：

- `initial_joint_positions` 也会先被裁剪到当前关节限位内

## 5. 怎么检查当前到底用了什么限位

运行：

```powershell
python SRL2_learning/scripts/inspect_end_effector_frames.py
```

现在它会打印：

- 当前生效的关节限位（弧度）
- 每个关节对应的上下限

实验主脚本在启动时也会打印：

- 当前生效的关节限位（弧度）

对应脚本：

- [inspect_end_effector_frames.py](/e:/project/codetest/SRL2_learning/scripts/inspect_end_effector_frames.py)
- [run_cartesian_target_experiment.py](/e:/project/codetest/SRL2_learning/scripts/run_cartesian_target_experiment.py)

## 6. 一个实际例子

假设你希望：

- `J1` 只能在 `-90° ~ 90°`
- `J2` 只能在 `-120° ~ -20°`
- `J3` 只能在 `-45° ~ 60°`

那么你在：

- [cartesian_target_experiment.json](/e:/project/codetest/SRL2_learning/configs/cartesian_target_experiment.json)

里写：

```json
"joint_position_limits_degrees": {
  "J1": [-90.0, 90.0],
  "J2": [-120.0, -20.0],
  "J3": [-45.0, 60.0]
}
```

然后运行：

```powershell
python SRL2_learning/scripts/inspect_end_effector_frames.py
python SRL2_learning/scripts/run_cartesian_target_experiment.py
```

---

## 7. 当前功能的边界

当前这套限位功能是“关节角数值限位”，不是更复杂的工业级约束系统。

也就是说，现在它支持：

- 每关节上下限
- IK 过程中裁剪

但暂时不支持：

- 速度限位和角度限位联动优化
- 碰撞约束
- 自定义软约束代价函数

不过对当前教学实验来说，这已经足够解决“不要在 0~360° 无限制求解”的问题。
