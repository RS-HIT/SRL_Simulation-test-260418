# 18_关节角拖动调试器说明

这个脚本的目的是：

- 实时显示每个关节当前角度
- 用滑块直接拖动每个关节
- 不做速度推进
- 你松手后，关节就停在当前角度
- 方便你观察每个关节的合适工作区间，再回填到限位配置里

## 脚本路径

- [debug_joint_angle_tuner.py](/e:/project/codetest/SRL2_learning/scripts/debug_joint_angle_tuner.py)

## 运行方式

```powershell
python SRL2_learning/scripts/debug_joint_angle_tuner.py
```

运行后会出现两部分：

1. 一个 MuJoCo viewer 窗口  
   用来实时看模型姿态。

2. 一个关节滑块窗口  
   用来拖动每个关节。

## 它为什么不会“按速度继续动”

原因很简单：

这个脚本不会做 `mj_step(...)` 的动力学推进，
它只会在每一帧做两件事：

1. 把滑块对应角度直接写进 `qpos`
2. 调用 `mj_forward(...)`

所以它是“位置直达”，不是“速度驱动”。

对应代码：

- [debug_joint_angle_tuner.py](/e:/project/codetest/SRL2_learning/scripts/debug_joint_angle_tuner.py)
- [model_context.py](/e:/project/codetest/SRL2_learning/src/srl2_learning/kinematics/model_context.py)

## 角度范围从哪里来

滑块上下限直接来自当前生效的关节限位。

这些限位配置在：

- [cartesian_target_experiment.json](/e:/project/codetest/SRL2_learning/configs/cartesian_target_experiment.json)

当前推荐字段：

```json
"joint_position_limits_degrees": {
  "J1": [-170.0, 170.0],
  "J2": [-170.0, 10.0],
  "J3": [-170.0, 170.0]
}
```

所以这个调试器的作用不是“无视限位乱转”，
而是：

**在你当前允许的范围内拖动，并帮助你重新判断这个范围是不是合理。**

## 你能看到什么

每个关节都会显示：

- 当前角度（弧度）
- 当前角度（角度）
- 已观察到的最小值
- 已观察到的最大值

窗口底部还会显示：

- 当前 flange 位置
- 当前 tool 位置

## 怎么把观察结果回填到配置

这个脚本里有两个按钮：

1. `打印当前关节角`
   会把当前每个关节的角度打印到终端。

2. `打印观察到的限位建议`
   会把当前观察到的最小/最大角度打印成 JSON，
   你可以直接复制回：

- [cartesian_target_experiment.json](/e:/project/codetest/SRL2_learning/configs/cartesian_target_experiment.json)

## 一个典型使用流程

1. 先运行调试器

```powershell
python SRL2_learning/scripts/debug_joint_angle_tuner.py
```

2. 拖动每个关节，观察：
- 模型姿态是否自然
- 哪些角度已经明显不适合工作
- flange / tool 的位置是否符合直觉

3. 拖到一批你觉得合理的边界后，点击：
- `打印观察到的限位建议`

4. 把打印出来的 JSON 回填到：
- [cartesian_target_experiment.json](/e:/project/codetest/SRL2_learning/configs/cartesian_target_experiment.json)

5. 再回到实验脚本里做正式求解：

```powershell
python SRL2_learning/scripts/run_cartesian_target_experiment.py
```
