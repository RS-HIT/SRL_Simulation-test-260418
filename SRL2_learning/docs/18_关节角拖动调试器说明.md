# 18_关节角拖动调试器说明

这个调试器的用途很单一：  
直接拖动每个关节角，实时看姿态，帮助你观察合理的关节限位和初始姿态。

对应脚本：

- [debug_joint_angle_tuner.py](/e:/project/codetest/SRL2_learning/scripts/debug_joint_angle_tuner.py)

## 运行方法

```powershell
python SRL2_learning/scripts/debug_joint_angle_tuner.py
```

运行后会出现两个界面：

1. 一个 MuJoCo viewer
2. 一个关节滑块窗口

滑块窗口里拖动某个关节后：

- 关节角会被直接写入 `qpos`
- 然后调用前向运动学刷新姿态
- 不做速度积分，不做惯性滑行
- 你松手后，关节就停在当前角度

## 初始视窗怎么调

现在调试器和末端实验 viewer 共用同一套相机初始化参数。  
你要改的文件是：

- [cartesian_target_experiment.json](/e:/project/codetest/SRL2_learning/configs/cartesian_target_experiment.json)

关键字段：

```json
"viewer_camera_lookat": [0.0, 0.0, 0.85],
"viewer_camera_distance": 2.6,
"viewer_camera_azimuth": 135.0,
"viewer_camera_elevation": -18.0
```

这些字段的含义：

- `viewer_camera_lookat`
  - 相机盯着看的点
  - 这是世界坐标系下的三维位置，单位米
- `viewer_camera_distance`
  - 相机离 `lookat` 点的距离
  - 越大看得越远，越小看得越近
- `viewer_camera_azimuth`
  - 水平绕着目标点转的角度
  - 可以理解成“从平面上的哪个方向看过去”
- `viewer_camera_elevation`
  - 俯仰角
  - 更负表示更俯视，更正表示更仰视

## 建议的调整顺序

### 1. 先改 `viewer_camera_lookat`

如果你觉得机器人一开始不在画面中心，优先改这个。

典型现象和调整方式：

- 模型偏左/偏右：
  - 改 `viewer_camera_lookat[0]`
- 模型偏前/偏后：
  - 改 `viewer_camera_lookat[1]`
- 模型偏高/偏低：
  - 改 `viewer_camera_lookat[2]`

### 2. 再改 `viewer_camera_distance`

如果模型太小看不清，减小一点。  
如果画面太近被裁切，增大一点。

### 3. 最后改 `viewer_camera_azimuth` 和 `viewer_camera_elevation`

这两个参数只改变“从哪个方向看”，不改变机器人本身的位置。

## 一个直接可用的试调流程

1. 运行：

```powershell
python SRL2_learning/scripts/debug_joint_angle_tuner.py
```

2. 观察当前视角问题。
3. 关闭窗口。
4. 修改 [cartesian_target_experiment.json](/e:/project/codetest/SRL2_learning/configs/cartesian_target_experiment.json) 里的相机参数。
5. 再运行同样的命令。
6. 重复几次，直到你得到满意的初始视图。

## 常见调整经验

- 想让镜头更靠近机器人：
  - 减小 `viewer_camera_distance`
- 想从另一侧看机器人：
  - 改 `viewer_camera_azimuth`
- 想更俯视一点：
  - 把 `viewer_camera_elevation` 调得更负
- 想让镜头盯住末端附近：
  - 把 `viewer_camera_lookat` 改到末端附近的世界坐标
