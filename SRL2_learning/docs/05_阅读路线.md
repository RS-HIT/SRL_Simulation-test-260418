# 05 阅读路线

## 这份文档是干什么的

这份文档不是讲“所有细节”，而是告诉你：

- 先看什么最容易入门
- 后看什么最能建立主流程概念
- 哪些文件现在就值得看
- 哪些文件先别硬啃

## 推荐阅读顺序

### 第一步：先建立全局印象

先看：

- `README.md`
- `docs/07_超级新手入门总览.md`
- `docs/08_主流程图解.md`

看懂这些就够了：

- 这个项目想让机械臂完成目标运动
- 主流程不是“目标 -> 电机”直连
- 学习版当前只保留了最小离线主链路

### 第二步：看最稳定、最容易确认的公式模块

再看：

- `src/srl2_learning/core/constants.py`
- `src/srl2_learning/core/joint_motor_mapper.py`

这一阶段重点理解：

- 为什么关节命令和电机命令不是一回事
- 为什么要有“映射”这一步

### 第三步：看状态更新

再看：

- `src/srl2_learning/core/state_tracking.py`

这一阶段重点理解：

- 为什么只有位置还不够
- 为什么系统总要记住“上一拍”的值
- 为什么低通滤波是为了“让信号别太抖”

### 第四步：看最小主链路

接着看：

- `src/srl2_learning/core/trajectory_planner.py`
- `src/srl2_learning/core/dynamics_service.py`
- `src/srl2_learning/core/controller_pipeline.py`

这一阶段重点理解：

- 一条最小主链路是怎么从目标走到执行命令的
- 哪些模块是真逻辑
- 哪些模块只是教学替身

### 第五步：最后看示例和测试

最后看：

- `examples/minimal_joint_motion.py`
- `tests/test_joint_motor_mapper.py`
- `tests/test_state_tracking.py`
- `tests/test_pipeline.py`

这一阶段重点理解：

- 这条最小链路已经验证了什么
- 哪些行为还不能说和原版完全等价

## 零基础读者的 3 天阅读安排

更详细的计划见：

- `docs/10_三天入门计划.md`

这里给你超简版：

### Day 1

- 只看文档
- 达标标准：能说清主流程和几个核心术语

### Day 2

- 只看最小主链路代码
- 跑示例，观察输入目标如何变成电机命令

### Day 3

- 回头看原始 `SRL2/main.cpp` 和 `SRL2/robot.cpp`
- 重点看“学习版里已经讲明白的部分，在原版里长什么样”

## 哪些是主流程文件

- `src/srl2_learning/core/controller_pipeline.py`
- `src/srl2_learning/core/trajectory_planner.py`
- `src/srl2_learning/core/state_tracking.py`
- `src/srl2_learning/core/joint_motor_mapper.py`

## 哪些是辅助文件

- `src/srl2_learning/core/constants.py`
- `src/srl2_learning/adapters/mock_actuator.py`
- `configs/offline_demo_config.json`

## 哪些地方先不要硬啃

对于零基础读者，下面这些内容现在先别硬啃：

- 原始 `SRL2/main.cpp` 的全部场景脚本
- 原始 `robot.cpp` 的完整状态机
- CAN / 485 / HoloLens / T265 / FT / MuJoCo / V-REP

原因很简单：

- 它们更接近真实工程细节
- 现在直接看，容易在“细节”里迷路
- 先看懂最小主链路，再回头看它们，理解成本会低很多
