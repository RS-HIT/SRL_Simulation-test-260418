# 10 三天入门计划

## 这份计划适合谁

适合下面这类读者：

- 以前没接触过机械臂项目
- 不熟悉控制、动力学、规划这些词
- 想先看懂主流程，而不是先被硬件细节劝退

## Day 1：先把全局看明白

### 只看什么

- `README.md`
- `docs/07_超级新手入门总览.md`
- `docs/08_主流程图解.md`

### 看懂什么就算达标

- 能用自己的话说清楚：
  - 这个项目是想让机械臂完成目标动作
  - 机械臂不能“想动就直接动”
  - 主流程为什么要经过规划、状态更新、映射、执行

### 今天先不要做什么

- 不要一上来啃原始 `SRL2/main.cpp`
- 不要急着看硬件通信和仿真细节

## Day 2：看最小主链路并实际跑一次

### 只看什么

- `src/srl2_learning/core/joint_motor_mapper.py`
- `src/srl2_learning/core/state_tracking.py`
- `src/srl2_learning/core/controller_pipeline.py`
- `docs/09_关键函数说明书.md`

### 跑哪些示例

运行：

```powershell
python scripts/run_minimal_example.py
python scripts/run_validation.py
```

### 重点观察什么输入输出

- 输入的目标关节命令是什么
- 规划后每一步位置是怎么变的
- 状态跟踪器如何补出速度和加速度
- 末步电机命令长什么样
- 哪些输出被明确标为“未验证”或“教学替身”

### 看懂什么就算达标

- 能说清楚“输入目标是怎么一步步变成电机命令的”

## Day 3：带着问题回头看原始项目

### 再回头看哪些原项目文件

- `SRL2/main.cpp`
- `SRL2/robot.cpp`
- `SRL2/dynamics.cpp`
- `SRL2/motionplanning.cpp`

### 带着哪些问题去看

- 学习版里的最小主链路，在原版里分别藏在哪些函数里
- 原版为什么会比学习版多这么多全局变量和模式分支
- 哪些地方是“主流程骨架”
- 哪些地方是“真实工程细节”

### 哪些地方先不要硬啃

- CAN / 485 通信细节
- HoloLens
- T265
- FT 传感器
- MuJoCo / V-REP
- Xenomai 实时任务细节

### 原因

- 这些内容不是不重要
- 而是它们更适合放在“已经看懂骨架之后”再看
- 现在硬啃，很容易把注意力从主流程转移到环境和协议细节上

## 三天之后你应该达到什么状态

如果这三天顺利，你至少应该能做到：

- 看懂学习版最小主链路
- 理解几个核心术语的大白话意思
- 分清哪些模块是真逻辑，哪些是教学替身
- 带着明确问题去看原始 `SRL2`，而不是盲看
